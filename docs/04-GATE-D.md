# 闸 D：盲读

## 做法

本赛题首届、无同题往届作，官网往届库需登录，因此用「多档模型独立盲读」代替混排打分：

- 给评委的只有**方案书页图**（PDF 渲染的 PNG），不给任何解释、不给代码；
- 评委来自不同模型档位（reasoning / default / lite），互不通气；
- 提问固定三句：① 哪一页/哪一句最不可信？② 哪个数字你认为站不住？③ 如果你是命题人，会扣哪一项分？
- 每一处意见都记账：改了什么、为什么改、或为什么保留。

## 判据

- 两位不同家族**独立**指到同一处 → 必须处理（改，或写明保留理由）；
- 只出现在一位评委的清单里 → 自行判断，但要在票面记一条；
- 处理后不再要求第二轮，除非改动涉及数字口径（此时必须重新渲染页图再读一次）。
