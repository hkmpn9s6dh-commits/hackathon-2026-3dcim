# 教训（本轮）

1. **能量守恒要落到节点上，不是落到总数上。** 把搬运能量的瓦数只加进"总功耗"、不进热网络，
   模型就会一边说"容量不够会慢"一边说"2 层也很快"。判据：任何一瓦都必须能指出它烧在哪一层。
2. **1D 热阻模型会允许非物理的热流密度。** 必须显式给 q_max；否则冷板 0.08 K/W 会被读成
   "24 mm² 能散 600 W"。这一条决定"墙"到底在温度轴上还是在热流密度轴上。
3. **占空比的基准要选对**：`s / 总吞吐上限` 与 `s / 单层上限` 差一个 N，会让"多一层更快"变成
   "多一层更慢"。平台检验（4→8 层差 <1%）是能自动抓到它的那条断言。
4. **节点的下标错一位，单层解析对齐就能抓住。** 本轮 `rhs[:n]` 应为 `rhs[1:n+1]`，
   症状是所有温度都恰好高/低一个 R_hs·P —— 肉眼看图看不出来。
5. **"堆得越高越快"的反例可以被算出来，而且不需要新器件**：只要吞吐上限写成
   `(q_max·A − P_static)/E_token`，N 就不在式子里。
